안녕하세요. **DevOps 엔지니어를 위한 LLM 에이전트 설계** 특강 안내드립니다.

## 무엇을 하나요

여러분의 AWS 계정에 **실제 EKS 클러스터**를 띄우고, ArgoCD 로 앱을 배포합니다.
그다음 매니페스트를 실제로 커밋해서 **진짜 장애**를 일으키고,
Bedrock 에이전트가 그 로그와 이벤트를 읽어 원인을 진단하고 복구까지 하는 것을 만듭니다.

모의 환경이 아닙니다. `kubectl get pods` 로 pod 가 죽는 것을 직접 보게 됩니다.

- 일시: (기입)
- 장소: (기입)
- 준비물: **노트북**, 첨부한 실습 폴더, 별도 전달드린 자격증명 네 줄

## 반드시 강의 전날까지 해주세요

환경 구축에 **25~35분**이 걸립니다. EKS 클러스터를 만드는 시간입니다.
당일 아침에 하면 강의 시작이 늦어지니 미리 부탁드립니다.

### 1. 파이썬 환경

**Windows (PowerShell)**

```powershell
cd student
python -m pip install -r requirements.txt
```

가상환경을 쓰고 싶으시면:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

`.venv\Scripts\Activate.ps1` 에서 실행 정책 오류가 나면 그 창에서만 한 번 풀어주세요.
`Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`

**macOS / Linux**

```bash
cd student
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

AWS CLI 는 필요 없습니다. 전부 파이썬으로 진행하며, VS Code 터미널에서 그대로 실행됩니다.

### 2. 받은 값 붙여넣기

```bash
cp .env.example .env               # Windows: copy .env.example .env
```

`.env` 위쪽에 전달드린 네 줄을 넣고, 알림 받을 이메일도 채워주세요.

```
STUDENT_NAME=<받은 이름>
AWS_ACCESS_KEY_ID=<받은 키>
AWS_SECRET_ACCESS_KEY=<받은 시크릿>
AWS_DEFAULT_REGION=ap-northeast-2
ALERT_EMAIL=<본인 이메일>
```

### 3. 배포하고 점검

```bash
python deploy_lab.py               # 25~35분
python check_env.py                # 10항목 전부 ✅
```

`ALERT_EMAIL` 을 채우셨으면 AWS 에서 구독 확인 메일이 옵니다.
**`Confirm subscription` 링크를 반드시 눌러주세요.** 안 누르면 진단 리포트가 안 옵니다.
빠뜨렸다면 나중에 `python alerts.py 본인메일` 로 추가할 수 있습니다.

❌ 가 하나라도 있으면 화면을 캡처해서 보내주세요.

### 자주 막히는 지점

| 증상 | 해결 |
|---|---|
| `pip install` 이 안 됨 | `pip install -r requirements.txt -i <사내 PyPI>` |
| `액세스 키가 올바르지 않습니다` | `.env` 값에 앞뒤 공백·따옴표 확인 |
| `AWS 연결 오류` | `export HTTPS_PROXY=http://<프록시>:<포트>` |
| 배포 중 실패 | 화면에 원인이 출력됩니다. 그대로 보내주세요 |
| Bedrock 에서 `marketplace` 언급 | **바로 알려주세요.** 계정 설정 문제입니다 |

## 알아두시면 좋은 것

- **파이썬을 잘 몰라도 됩니다.** 코드 골격이 다 있고 빈칸 몇 개만 채웁니다.
- **쿠버네티스를 깊이 알 필요도 없습니다.** 필요한 것은 그때그때 설명합니다.
- `kubectl` 이 있으면 좋지만 없어도 됩니다. `python kube.py pods` 로 대체됩니다.

## 비용과 정리

실습 중 EKS 클러스터가 돌아가므로 **시간당 약 $0.2** 가 발생합니다.
강의 마지막에 다 같이 `python cleanup.py` 를 실행해 전부 지웁니다.

**전날 미리 배포하신 경우, 그날 밤 동안 요금이 나갑니다.**
아깝다면 배포 후 `python cleanup.py` 로 지웠다가 당일 아침에 다시 만드셔도 됩니다.
다만 그러면 25~35분이 다시 필요합니다. 하루치는 몇 천 원 수준이니 그냥 두시길 권합니다.

궁금한 점 있으면 편하게 연락 주세요.
